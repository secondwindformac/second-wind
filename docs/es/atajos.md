# Atajos de teclado tras instalar MacConLinux

La tecla **⌘ Cmd** de tu teclado Apple funciona como en macOS (lo hace el
servicio Toshy, que corre invisible de fondo):

| Atajo | Qué hace |
|---|---|
| `Cmd + Espacio` | Spotlight (buscar apps y archivos) |
| `Cmd + C / V / X` | Copiar / pegar / cortar |
| `Cmd + Z` / `Cmd + Shift + Z` | Deshacer / rehacer |
| `Cmd + A` | Seleccionar todo |
| `Cmd + T` | Nueva pestaña |
| `Cmd + W` | Cerrar pestaña/ventana |
| `Cmd + Q` | Salir de la aplicación |
| `Cmd + Tab` | Cambiar de aplicación (entre TODAS las apps de todos los escritorios, como en Mac) |
| `Cmd + H` | Minimizar/ocultar la ventana |
| `Cmd + Shift + 3` | Captura de pantalla completa |
| `Cmd + Shift + 4` | Captura de la ventana activa |
| `Cmd + Shift + 5` | Captura con opciones (seleccionar zona, grabar…) |
| `Cmd + ,` | Preferencias de la app (donde exista) |
| En la Terminal: `Cmd + C` | Copia texto (Ctrl+C sigue interrumpiendo programas, como en Mac) |

Gestos del trackpad (nativos de Ubuntu):

| Gesto | Qué hace |
|---|---|
| 3 dedos hacia arriba | Vista general (Mission Control) |
| 3 dedos a los lados | Cambiar de escritorio |
| Esquina superior izquierda del ratón | Vista general (esquina activa) |

Detalles técnicos: el mapeo por aplicación necesita la extensión Xremap
(instalada por MacConLinux) y se activa al cerrar sesión. Si algún día
quieres ver el panel de control del teclado, ejecuta `toshy-tray` en una
terminal; MacConLinux lo oculta por defecto para no confundir.
